# CodeAlpha Machine Learning Internship — Modified Architecture Edition

This repository contains all four CodeAlpha Machine Learning tasks with slightly revised model architectures while preserving the original objectives and Streamlit workflows.

## Projects

1. **CodeAlpha_CreditScoringModel** — creditworthiness classification using linear/tree learners plus a hybrid soft-voting ensemble.
2. **CodeAlpha_EmotionRecognitionFromSpeech** — MFCC speech emotion recognition using a Conv1D + BiGRU + attention network.
3. **CodeAlpha_HandwrittenCharacterRecognition** — handwritten digit/character recognition using a multi-stage adaptive-pooling CNN.
4. **CodeAlpha_DiseasePrediction** — Breast Cancer Wisconsin classification using Logistic Regression, RBF SVM, Extra Trees, and a soft-voting ensemble.

See `ARCHITECTURE_CHANGES.md` for the exact differences from the original version.
